# MW数据转发器 · 命令行版本设计说明

> 对应版本: v6.4 (与 `git tag` / `--version` / GUI 标题一致)
> 本文描述命令行版本的定位、入口分发、规格语法、行为语义与错误处理, 与当前代码一一对应。

## 1. 定位与设计原则

| 使用接口 | 目标用户 | 形态 |
|---|---|---|
| GUI | 人类 | 窗口交互, 实时预览/对端列表/动态限速 |
| CLI | 脚本 / AI agent | **单次运行**: argv 传入配置 → 立即开始转发 → Ctrl+C 或 `--duration` 到时 → 退出 |

CLI 刻意设计为**无交互、无会话状态**:

- 不等待 stdin, 不进入 REPL/TUI —— 这类交互式界面需要 PTY 和会话保持, AI agent 与脚本难以驱动且易挂死;
- 全部输出走 stdout/stderr, 可被管道捕获; 结果用**退出码**表达;
- 需要调整配置 = Ctrl-C 退出 → 修改参数 → 重新执行。

CLI 与 GUI **共享同一个 core 转发引擎** (`transponder/core/`), 功能一一对应, 仅使用接口不同。

## 2. 入口分发规则 (`python -m transponder` / 源码)

| 启动方式 | 行为 |
|---|---|
| 无参数 | 打开图形界面 |
| `--list-serial` / `--list-net` / `--version` / `--help` | 直接执行输出后退出, 不开界面 |
| `-m/-w/...` 且**无** `--nogui` | 打开图形界面, 并把参数填充到界面对应配置项 |
| `--nogui` | 纯命令行转发模式 (本文档主体) |
| 无图形环境且需 GUI | 报错退出, 退出码 3 |

注: 打包 exe 专用于 GUI (任何参数均进入图形界面); 命令行模式仅通过源码运行。

## 3. 退出码

| 码 | 含义 |
|---|---|
| 0 | 正常结束 (转发完成/查询成功) |
| 1 | 运行错误 (连接失败、文件不存在、串口被占用等, 具体信息在 stderr) |
| 2 | 参数错误 (未知类型、缺必填参数、非法值, 具体信息在 stderr) |
| 3 | 无图形环境 (仅 GUI 路径) |

## 4. 数据源规格语法 (SPEC)

统一格式: `类型:参数=值,参数=值` —— 顺序任意, 未给出的参数取默认值。
类型与参数完整清单 (与 `--help` 尾部说明一致):

### serial — 串口
| 参数 | 默认 | 说明 |
|---|---|---|
| port | (必填) | 串口名, 如 `COM3` / `/dev/ttyUSB0`; 可先用 `--list-serial` 查询 |
| baud | 115200 | 波特率 |
| data | 8 | 数据位 5/6/7/8 |
| parity | N | 校验 N=无 E=偶 O=奇 |
| stop | 1 | 停止位 1/2 |
| flow | none | 流控 none=无 rtscts=RTS/CTS |

### file-send — 文件读→发送 (单向, 读完即止)
| 参数 | 默认 | 说明 |
|---|---|---|
| path | (必填) | 文件路径 |
| b / kb / mb | 0/0/0 | 限速 = b + 1024×kb + 1024×1024×mb 字节/秒; 全 0 = 不限速; 传输中输出进度 |

### file-recv — 文件写←接收 (单向)
| 参数 | 默认 | 说明 |
|---|---|---|
| path | (必填) | 文件路径 |
| append | 0 | 1=追加写入, 0=覆盖 |

### tcp-client — TCP 客户端
| 参数 | 默认 | 说明 |
|---|---|---|
| host | (必填) | 远端服务器地址 |
| port | (必填) | 远端服务器端口 |
| local_host | (空) | 本地绑定 IP (空=系统自动选择) |
| local_port | 0 | 本地绑定端口 (0=系统自动分配) |

### tcp-server — TCP 服务端
| 参数 | 默认 | 说明 |
|---|---|---|
| host | 0.0.0.0 | 监听地址 |
| port | (必填) | 监听端口 |
| backlog | 0 | 监听队列大小 (0=系统默认) |
| primary | (空) | 主要对端 `IP:PORT`; 指定后仅与该客户端点对点; 不指定=发给全部客户端并接收全部; 主要对端断开自动恢复全部模式 |

### udp — UDP 单播
| 参数 | 默认 | 说明 |
|---|---|---|
| host | 0.0.0.0 | 本地绑定地址 |
| port | 0 | 本地绑定端口 (0=自动分配) |
| peer | (空) | 对端 `IP:PORT`; 不填=收到第一帧数据后锁定其来源; 填写后仅与该对端收发 |

### multicast — 组播
| 参数 | 默认 | 说明 |
|---|---|---|
| group | (必填) | 组播地址, 必须在 224.0.0.0/4 范围 |
| port | (必填) | 组播端口 |
| local_host | 0.0.0.0 | 本地接口 (0.0.0.0=系统按路由选择网卡) |
| ttl | 1 | TTL |

### broadcast — 广播
| 参数 | 默认 | 说明 |
|---|---|---|
| addr | 255.255.255.255 | 广播地址 (可用 `--list-net` 查看网卡对应广播地址) |
| port | (必填) | 广播端口 |
| local_host | 0.0.0.0 | 本地绑定地址 |
| local_port | 0 | 本地接收端口 (0=自动分配) |

## 5. 行为语义 (与 GUI 完全一致, 由同一 core 实现)

- **双向转发**: M 收到的数据发给 W, W 收到的数据发给 M; 直到 Ctrl+C / `--duration` 到时。
- **文件单向**: file-send 只发不收, file-recv 只收不发; 两侧都是文件时执行单向复制(覆盖)。
  对端为 file-send 时的反向数据**不算错误**, 累计忽略字节数低频提示 (相同文本事件 5 秒去重)。
- **组播/广播自回环过滤**: 自动丢弃自己发出的回环数据 (按 来源IP=本机 且 来源端口=发送socket端口 识别),
  本机其他程序可正常互通 (便于同机联调)。
- **落地记录**: `--log-dir` + `--log-m/--log-w` 开启后, 每次运行在 basedir 下新建
  时间戳文件夹 `YYYY-MM-DD_HH-MM-SS`, 内含 `M.bin`/`M.txt`/`W.bin`/`W.txt`;
  BIN=原始二进制不加任何附加信息; TXT=文本, 可选周期时间戳行 (`[YYYY-MM-DD HH:MM:SS.mmm]`, 自动换行)。
  进程退出时句柄全部释放。
- **事件输出**: 运行期事件以 `[事件] 消息` 格式逐行输出到 stdout (客户端接入/断开、文件读完、限速忽略等)。
- **结束摘要**: 退出前最后一行输出 `结束: M→W X 字节, W→M Y 字节`。
- **文件进度**: file-send 传输中输出 `\r进度: done/total (pct%)`, 约每 256KB 刷新一次。

## 6. 输出流约定 (供 agent 解析)

- stdout: 事件行 (`[事件] ...`)、进度行 (`进度: ...`)、落地目录行、结束摘要行 —— 全部可捕获;
- stderr: 错误 (`错误: ...`) 与参数错误 (`参数错误: ...`) —— 用于诊断;
- 退出码见第 3 节。

## 7. 版本号

与 git 提交序列一致 (每轮修改意见/功能迭代一提交)。`--version`、GUI 窗口标题、
GUI 标题栏均显示同一版本号; 源码运行时优先读取 git 精确标签, exe 内置打包时固化的版本。
